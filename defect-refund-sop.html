次品退货 SOP（详细操作手册）

捷展贸易 · 最后更新：2026-09-01

📌 一句话流程：登记次品（拍照+采购单号）→ 系统自动匹配商品/供应商/退货地址 → 点「一键退货」创建聚水潭退货单 → 点「🖨️ 面单」打印圆通电子面单 → 寄回 → 1688 后台申请退款（1688单）→ 卖家收货 → 退款完成。

一、系统组成

系统职责
次品图片收集系统采集次品图片、状态追踪、供应商/商品/地址自动匹配、一键退货（建聚水潭单）、打印面单
聚水潭 ERP商品资料、供应商资料、采购单、采购退货订单（shopId=21571486 外贸采购退货）、电子面单数据源
1688 后台1688 采购单的退款申请（人工提交、带图片凭证）与退款进度

自动识别来源：登记时若带 1688 平台订单号 → 1688 流程；否则 → 非 1688（线下档口）流程。两者都要质检、都要退次品。

二、快速上手（3 步）

  1. 登记：扫描/输入采购单号 → 输入次品明细（如 Y6661黑色M×1 或 E669622XL×2）→ 拍照上传 → 保存。
  2. 看状态：系统自动从聚水潭匹配颜色/码数、供应商、退货地址，页面显示「处理中 / 待补地址 / 未匹配」徽章。
  3. 退货：点「📦 退货」一键创建聚水潭退货单 → 点「🖨️ 面单」打印圆通电子面单 → 打包寄回。
⚠️ 退货单不会自动创建，只有点了「一键退货」才会调用聚水潭 API 创建；后台定时任务只更新状态/映射，不建单。

商品明细展示

  • 卡片上显示 🏪 供应商名称；🔵1688 / 🟡非1688 来源标签
  • 已下单显示内部单号：✅ 8370xxx；退款旁显示 📦 退货单号

六、1688 采购单 — 完整流程

操作步骤（每一步都重要）

  1. 登记：仓库扫码登记次品 → 拍照上传（登记时带 1688 平台订单号）。
  2. 点「📦 退货」：弹窗确认后，系统立即调用聚水潭 API 创建采购退货订单（同供应商合并，即时回写内部单号，标记 [退货:已下单:xxxx]）。
  3. 打印面单：点「🖨️ 面单」→ 系统用圆通电子面单接口生成面单（聚水潭同款版式：收件信息=供应商退货地址，寄件=次品退货部，含三段码/条码/快递单号），可打印寄回。
  4. 1688 申请退款：点「📦 退货」还会打开 1688 后台退货页面（系统带 1688 订单链接）。人工在 1688 后台提交退款申请，并把次品图片作为凭证上传。
  5. 等卖家同意：系统每 2 小时同步 1688 退款进度（状态显示「等待卖家同意」）。
  6. 填快递单号：卖家同意后，1688 退款申请进入「等待买家退货」，把面单上的快递单号填到 1688 退款申请单里。
  7. 寄回：用打印好的圆通面单发货。
  8. 卖家收货 → 退款完成：1688 状态变「退款中/等待卖家收货」，卖家确认收货后「退款成功」。
登记次品 → 📦一键退货(建聚水潭单+开1688退货页) → 🖨️打面单 → 1688后台提交退款申请(带图) → 等待卖家同意 → 填快递单号(等待买家退货) → 寄回 → 等待卖家收货 → 退款完成 ↓ 卖家拒绝/申请失败 → 异常（人工跟进）
⚠️ 两条线并行、缺一不可：① 聚水潭退货单（用于打面单/物流）；② 1688 退款申请（用于拿回货款）。图片凭证无法自动搬运到 1688，必须人工在 1688 后台上传。

各节点参考时间

节点时间
一键退货 → 聚水潭退货单创建即时（点击后立即调用 API）
同步 1688 退款进度每 2 小时自动（人工可点刷新入口）

七、非 1688 采购单 — 完整流程

操作步骤

  1. 登记：扫码登记次品 → 拍照上传。
  2. 系统自动匹配商品颜色/码数、供应商、退货地址（来自聚水潭资料，每 2 小时自动更新）。
  3. 确认卡片显示「⏳ 处理中」+ 🏪 供应商。
  4. 点「📦 退货」→ 系统立即创建聚水潭采购退货订单（[退货:已下单:xxxx]）。
  5. 点「🖨️ 面单」→ 生成并打印圆通电子面单。
  6. 打包寄回供应商（面单上的收件地址即供应商退货地址）。
  7. 流程结束（显示「已完成」）。
登记次品 → 自动匹配(商品/供应商/地址) → 📦一键退货(建聚水潭单) → 🖨️打面单 → 寄回 → 完成 ↓ ↓ 未匹配(补商品/供应商) 待补地址(补地址)
💡 非 1688 不走 1688 退款流程；退货单创建后即视为完成，主要靠聚水潭单打面单/物流。

八、一键退货（创建聚水潭退货单）

  • 只有点「📦 退货 / 一键退货」才会创建聚水潭退货单；后台定时任务不会自动建单。
  • 前端直接调用退货服务（Cloudflare Worker return-worker）→ 调聚水潭 /open/jushuitan/orders/upload 创建订单。
  • 订单推送店铺：shopId=21571486（外贸采购退货店铺）。
  • 创建成功后回写内部单号并标记 [退货:已下单:内部单号]；失败标记 [退货:失败]（可「🔄 重试」）或 [退货:异常:单号]。
  • 1688 与非 1688 都会建聚水潭单（1688 建单用于电子面单/物流，退款另走 1688 平台）。
  • 按供应商合并：同一采购单内同供应商的次品合并为一个退货订单。
⚠️ 建单前请确认卡片有供应商+退货地址（处理中徽章）；「待补地址/未匹配」的记录无法建单打印。

九、面单打印（🖨️ 面单）

  • 按钮出现条件：该采购单已匹配到有效供应商 + 退货地址。
  • 点击后：系统调用圆通电子面单 API（yto-proxy）实时生成面单，显示快递单号（YT 开头）。
  • 面单版式：聚水潭同款（收件信息自动换行；寄件：谢焕君 13316255984 广东省广州市番禺区大石街道会江鸿盛三路9号高昇产业园A301；含三段码/大单号/左右快递单号/明细区）。
  • 打印后把快递单号填到 1688 退款申请（1688 单）。
  • 若显示「暂无退货地址」，需先补供应商退货地址。

十、重新匹配

  • 适用：未匹配 + 退货失败的记录（点「重新匹配」批量触发）。
  • 作用：清除失败标签，按最新聚水潭商品/供应商/地址映射重新匹配；不会自动建单。
  • 匹配成功后需手动点「一键退货」。
  • 也可对单个失败记录点「🔄 重试」。

十一、商品/供应商/退货地址自动同步（方案A）

数据来源更新方式
商品（SKU→款号·颜色·码数）聚水潭普通商品资料（仅 15 个服装分类：背心/短裤/长裤/七分裤/短袖衬衫/套装/长袖衬衫/毛衣/外套/卫衣/羽绒外套/短袖T/长袖T/马甲/裙子）每 2 小时自动（本机计划任务 JST-AutoSync → 聚水潭 → Supabase mapping_data）
供应商（款号→供应商）聚水潭商品资料 supplier_name + 供应商表同上，每 2 小时
退货地址（供应商→地址）聚水潭供应商资料（address/mobile/contacts）同上，每 2 小时
  • 前端每次打开页面从 Supabase mapping_data 读取最新映射，失败用本地 JSON 兜底。
  • 新增商品/供应商/地址：在聚水潭维护好后，最多 2 小时自动进入次品系统，无需人工处理。
  • 云备份方案：Cloudflare Worker（jst-sync-worker）每天 03/11/19 点自动同步（需聚水潭把 Cloudflare 出口网段加入 IP 白名单后生效）。
⚠️ 供应商名称带 * 号（打码，如 吕**-整烫）或为「市场」的，一律视为未匹配，归入未匹配状态。

十三、注意事项与常见问题
