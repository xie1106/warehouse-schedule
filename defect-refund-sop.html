🦐 次品退款 SOP

Standard Operating Procedure · 捷展贸易 · 次品图片收集系统 · 2026-08更新

一、系统概览

系统职责
次品图片收集系统收集次品图片 + 退款/退货状态追踪 + 一键退货下单
聚水潭ERP采购单管理、质检次品数量（权威来源）、退货订单推送
1688后台退款申请、退款状态（1688采购单专用）
💡 系统自动识别采购单类型：有1688平台订单号 → 1688流程；无平台订单号 → 非1688流程

二、1688采购单 — 退款流程

1
仓库登记次品
打开次品收集系统 → 扫码/输入采购单号 → 选SKU和数量 → 拍照上传 → 提交
2
确认退款数量
以聚水潭质检次品数（qc_defective_qty）为准，非收集系统登记数。
本次退款数 = 聚水潭质检次品数 − 已退款中/已退款数量
⚠️ 前提：前一条退款记录状态必须先从1688后台同步
3
提交1688退款
点击收集系统"📦退货"按钮 → 跳转聚水潭1688详情页 → 提交退款（带图片凭证）
• 一个采购单所有退货SKU合并为一个退款申请
• goodsStatus选 refundWaitBuyerReceive
4
状态追踪
系统定期同步1688退款状态，自动更新badge（退款中/已退款/退款关闭）

状态流转

正常流程：

未申请→ 等待卖家同意→ 等待买家退货→ 等待卖家收货→ 退款成功 ✅

异常：

卖家拒绝 / 退款关闭→ 需重新申请

三、非1688采购单 — 退货流程

1
仓库登记次品
同上，系统自动标记为"非1688"
2
编辑确认（可选）
点"✏️编辑" → 确认SKU和数量 → 可修改/删除 → 保存
3
一键退货
点"📦退货"按钮 → 确认 → 系统自动：
① 匹配供应商（聚水潭采购单 → 款号映射 → 腾讯文档）
② 查找退货地址（供应商地址表 66个档口）
③ 创建聚水潭退货订单（推送到"外贸采购退货"店铺）
④ 回传内部单号到badge
4
等待处理
提交后约2分钟内自动创建订单，badge从"⏳处理中"变为"✅ 订单号"
5
打印面单发货
去聚水潭"外贸采购退货"店铺 → 找到订单 → 打面单 → 发货

状态流转

待处理→ ⏳ 处理中→ ✅ 已下单(单号)

异常：

待处理→ ❌ 失败（无法匹配供应商）→ 🔄 重试
⚠️ 匹配失败处理：异常tab显示红色badge，需人工确认供应商信息后补充映射表，再点"🔄重试"

四、自动化机制

机制频率说明
非1688退货订单创建每2分钟检查待处理请求，自动创建聚水潭订单
1688退款状态同步按需/手动触发从1688后台拉取退款进度更新badge
历史数据清理每2分钟退款成功/已下单超过30天自动删除

五、关键规则

规则说明
退款数量来源聚水潭 qc_defective_qty，不以收集系统登记数为准
同SKU多批次不同批次独立追踪，不自动合并
非1688退货地址优先聚水潭供应商API → 款号→供应商映射 → 腾讯文档地址表
通用供应商supplier_id 1026703(整烫)/1401348(市场) 视为无效，走款号映射
退货订单店铺推送到 shopId=21571486（外贸采购退货）
订单格式不插入商品明细，备注写"采购单xxx | SKU明细 | 合计N件"
✅ 总结：
• 1688采购单：登记 → 确认质检数 → 1688提交退款 → 系统追踪状态
• 非1688采购单：登记 → 编辑确认 → 一键退货 → 自动创建订单 → 打面单发货
