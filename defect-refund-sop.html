次品退货 SOP（详细操作手册）

捷展贸易 · 最后更新：2026-09-02

📌 一句话流程：登记次品（拍照+采购单号）→ 系统自动匹配商品/供应商/退货地址 → 点【🖨️ 面单】直接打印圆通电子面单 → 打包寄回 → 1688 采购单再点【🔗 1688后台】人工申请退款并填快递单号 → 卖家收货 → 退款完成。
重要：本系统不再通过「退货按钮/聚水潭API」创建退货单，面单直接打印。

一、系统组成

系统职责
次品图片收集系统采集次品图片、状态追踪、商品/供应商/地址自动匹配、打印面单、跳转1688后台
聚水潭 ERP商品资料、供应商资料、采购单、退货地址数据源（只作为数据来源，不建退货单）
1688 后台1688 采购单的退款申请（人工提交、带图片凭证）与退款进度、填写快递单号

自动识别来源：登记时若带 1688 平台订单号 → 1688 流程；否则 → 非 1688（线下档口）流程。两者都要质检、都要退次品。

二、快速上手（3 步）

  1. 登记：扫描/输入采购单号 → 输入次品明细（如 Y6661黑色M×1 或 E669622XL×2）→ 拍照上传 → 保存。
  2. 看状态：系统自动匹配颜色/码数、供应商、退货地址，记录显示「待处理」；若缺要素会标注「未匹配：缺XX」。
  3. 打面单寄回：点【🖨️ 面单】打印圆通电子面单 → 打包寄回；1688 单再点【🔗 1688后台】申请退款并填快递单号。
⚠️ 系统不会自动创建任何聚水潭退货单，也不再需要"退货"按钮；打印面单就是发货动作。

五、记录合并与展示规则

合并显示（同一张卡片）

  • 只有：相同采购单号 + 状态为待处理（无退货、无退款标签）的记录才合并。

独立显示（一张卡片一条记录）

  • 有退货标签 / 有退款标签 / 已处理完成的记录，全部独立显示，不合并。
  • 即：同采购单号下，只要状态不是待处理，每条记录单独一张卡片。

商品明细展示

  • 格式：款号 · 颜色 · 尺码 ×数量，多款之间用红色竖线 | 分隔。
  • 颜色/尺码来自聚水潭商品资料（自动匹配）。
  • 卡片显示 🏪 供应商名称；🔵1688 / 🟡非1688 来源标签。
  • 搜索框支持：采购单号 + 快递单号 + 备注内容。

六、1688 采购单 — 完整流程

操作步骤

  1. 登记：扫码登记次品 → 拍照上传（登记时带 1688 平台订单号）。
  2. 系统自动匹配颜色/码数、供应商、退货地址，显示「待处理」。
  3. 点【🖨️ 面单】：直接打印圆通电子面单（收件=供应商退货地址，寄件=次品退货部，含快递单号/三段码）。
  4. 点【🔗 1688后台】：跳转到 1688 订单详情页，人工提交退款申请（带次品图片凭证）。
  5. 等卖家同意（系统每 2 小时同步状态，显示「等待卖家同意」）。
  6. 填快递单号：卖家同意后 1688 显示「等待买家退货」，把面单上的快递单号填进 1688 退款申请。
  7. 用打印好的面单打包寄回。
  8. 卖家收货 → 退款完成。
登记次品 → 待处理(自动匹配) → 🖨️打面单 → 🔗1688后台提交退款申请(带图) → 等待卖家同意 → 填快递单号(等待买家退货) → 寄回 → 等待卖家收货 → 退款完成 ↓ 退款被拒/关闭 → 异常（人工跟进重新申请）
⚠️ 退款申请与图片凭证必须人工在 1688 后台操作（图片无法自动搬运到 1688）。

各节点参考时间

节点时间
登记 → 待处理（自动匹配完成）即时
打印面单即时（圆通接口实时返回）
同步 1688 退款进度每 2 小时自动
等待卖家同意1–3 天
买家退货（填单号+寄回）打面单后 1–3 天
卖家收货 → 退款完成卖家确认后即时

七、非 1688 采购单 — 完整流程

操作步骤

  1. 登记：扫码登记次品 → 拍照上传。
  2. 系统自动匹配商品颜色/码数、供应商、退货地址（来自聚水潭资料，每 2 小时自动更新），显示「待处理」。
  3. 点【🖨️ 面单】→ 直接生成并打印圆通电子面单。
  4. 打包寄回供应商（面单收件地址=供应商退货地址）。
  5. 流程结束。
登记次品 → 待处理(自动匹配) → 🖨️打面单 → 寄回 → 完成 ↓ 未匹配(缺供应商/地址/颜色/码数 → 按原因处理)
💡 非 1688 不走 1688 退款流程；打印面单寄回即完成。如面单打印失败会标记「❌ 面单异常」。

八、面单打印（🖨️ 面单）

  • 按钮出现条件：该采购单已匹配到有效供应商 + 退货地址（待处理状态）。
  • 点击后：系统调用圆通电子面单 API（yto-proxy）实时生成面单，显示快递单号（YT 开头）。
  • 面单版式：聚水潭同款（收件信息自适应换行；寄件：谢焕君 13316255984 广东省广州市番禺区大石街道会江鸿盛三路9号高昇产业园A301；含三段码/大单号/左右快递单号/明细区）。
  • 打印成功后自动清除 [面单:异常] 标记；失败自动写入 [面单:异常:原因] 并显示「❌ 面单异常」。
  • 打印后把快递单号填到 1688 退款申请（1688 单）。
⚠️ 缺退货地址的采购单无法打印面单（未匹配：缺退货地址），需先补供应商退货地址。

九、未匹配原因与处理

未匹配原因含义处理办法
缺供应商未匹配到供应商（含供应商带 * 号/市场）等聚水潭脱敏；或在聚水潭补充商品供应商资料（≤2小时自动同步）
缺退货地址有供应商但无退货地址在聚水潭供应商资料补地址（≤2小时同步），或联系管理员手工补
缺颜色 / 缺码数商品资料里颜色/码数为空在聚水潭商品资料补全属性（≤2小时同步）
缺商品资料SKU 不在系统收录范围（15个服装分类之外 或 聚水潭查无此SKU）核对商品编码是否正确；确认分类是否在允许清单内
缺商品明细记录里没有可解析的 SKU×数量编辑记录补全明细
💡 未匹配的记录仍会显示"待处理"徽章，并在下方标注「⚠️ 未匹配：缺XX、缺XX」，方便一眼看出原因。

十、异常的定义与处理

异常类型判定处理
退款被拒退款状态 ∈ 退款关闭 / 卖家拒绝 / 卖家拒绝申请 / 卖家拒绝退款 / 申请失败去 1688 后台查看拒绝原因，重新申请或人工协商
快递单号获取异常记录带 [面单:异常:原因] 标签，显示「❌ 面单异常」稍后重试打印；仍失败联系管理员查圆通接口/地址完整性

十一、商品/供应商/退货地址自动同步

数据来源更新方式
商品（SKU→款号·颜色·码数）聚水潭普通商品资料（仅 15 个服装分类：背心/短裤/长裤/七分裤/短袖衬衫/套装/长袖衬衫/毛衣/外套/卫衣/羽绒外套/短袖T/长袖T/马甲/裙子）每 2 小时自动（本机计划任务 → 聚水潭 → Supabase mapping_data）
供应商（款号→供应商）聚水潭商品资料 supplier_name + 供应商表同上，每 2 小时
退货地址（供应商→地址）聚水潭供应商资料（address/mobile/contacts）同上，每 2 小时
  • 前端每次打开页面从 Supabase mapping_data 读取最新映射，失败用本地 JSON 兜底。
  • 新增商品/供应商/地址：在聚水潭维护好后，最多 2 小时自动进入次品系统，无需人工处理。
⚠️ 供应商名称带 * 号（打码）或为「市场」的，一律视为未匹配（缺供应商）。

十三、注意事项与常见问题

问题处理
显示「未匹配：缺供应商」① 供应商带 * 号/市场 → 等脱敏；② 新供应商 → 聚水潭建资料后 2 小时自动匹配
显示「未匹配：缺退货地址」聚水潭供应商资料补 address/mobile/contacts，最多 2 小时自动同步
显示「未匹配：缺颜色/缺码数」聚水潭商品资料补全属性，最多 2 小时自动同步
没有「🖨️ 面单」按钮供应商或退货地址未匹配（未匹配），先解决匹配问题
打印面单失败 / 面单异常检查供应商地址是否含电话且完整；圆通接口异常时稍后重试
1688 退款状态不变退款进度每 2 小时同步一次；紧急联系管理员手动刷新
旧「已下单/失败/异常」记录旧流程历史数据，保留展示；不影响新流程（直接打面单）
  • 备注/明细不能用换行符（用分号分隔）。
  • 历史数据永久保留；删除操作需谨慎（仅管理员）。
  • 退货地址「拒收到付件」的，寄件务必选择寄付。
